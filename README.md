### 🏆 Featured Projects

#### 💪 SDFitness — FitGenius AI *(Production)*
> `Python · Flask · Scikit-learn GBM · Gemini 2.0 Flash · React 18 · Node.js · MongoDB · Docker`

A full-stack gym management platform powered by a **custom-trained Gradient Boosting model** and **Google Gemini 2.0 Flash** LLM integration.

- 🧠 **4-tier ML pipeline**: live price scraping (Playwright) → fuzzy matching (TheFuzz) → GBM inference (~20ms) → Gemini LLM enrichment
- 🛒 **Dynamic Knapsack Virtual Pantry** — simulates real grocery shopping with bulk-buy rules and pantry reuse across meal slots
- 📊 Budget-aware **7-day meal plans** priced in LKR using real Keells/Cargills supermarket data
- 🐳 5 services containerised with **Docker Compose** · ML service covered with pytest
- 💬 Gemini 2.0 Flash for recipe generation and natural-language meal descriptions
- 📋 **40+ REST API endpoints** · **20+ MongoDB collections** · Admin analytics dashboard
